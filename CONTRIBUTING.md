# Contributing

prismBar is developed in public, but external code contributions are temporarily closed while the clean-room baseline and contributor licensing workflow are established.

Bug reports, reproducible macOS 27 behavior reports, accessibility feedback, security reports, and product ideas are welcome.

Do not submit:

- code copied or adapted from Ice, Thaw, or another GPL implementation
- screenshots, logs, fixtures, or tests containing private menu bar content
- credentials, environment values, signing materials, provisioning profiles, device identifiers, or personal paths
- private or undocumented Apple APIs
- generated code whose provenance and license cannot be established

Opening an issue does not grant permission to publish private information. Security reports must follow `SECURITY.md`.
